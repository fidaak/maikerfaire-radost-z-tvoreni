// 01 --3d-tisk

Voron 3D tiskárny

Vlastnoručně postavené tiskárny Voron 2.4r2 a Voron 0.2. CoreXY, Klipper firmware, přesnost pod 0.1 mm.

// 02 --rc-auto

RC LEGO auto

Motorizované LEGO RC auto s drony komponenty a upraveným firmware. Stavba, úpravy, jízda.

Henna malování

Naše dcera předvádí tradiční umění henna malování na kůži. Přijďte si nechat namalovat vlastní vzor!

Compliant modely

3D tištěné modely s pružnými mechanismy – pohyb bez kloubů, jen díky geometrii. Print-in-place magie.

Foto → 3D model

Experimentální pipeline: vyfotíte objekt a pomocí LLM vznikne parametrický 3D model k vytištění.
