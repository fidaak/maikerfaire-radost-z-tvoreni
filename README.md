# Matterhackers Radošov: Radost z tvoření

Rodinný projekt pro **MakerFaire Karlovy Vary 2026**.

Jsme rodina tvůrců (Filip Novotný, fyzik a maker, s rodinou ve věku 7–40+), kteří staví tiskárny, navrhují modely, bastlí RC auta a tvoří umění na kůži.

**Odkaz na projekt:** [makerfaire.cz/projekt/matterhackers-radosov-radost-z-tvoreni](https://makerfaire.cz/projekt/matterhackers-radosov-radost-z-tvoreni/)

## Co představujeme

| Projekt | Popis |
|---------|-------|
| **Voron 3D tiskárny** | Voron 2.4r2 a Voron 0.2 – sestavené vlastníma rukama |
| **RC LEGO auto** | Motorizované RC auto z LEGO s drony komponenty a upraveným firmware |
| **Henna malování** | Dcera předvádí tradiční henna malování na kůži |
| **Compliant modely** | 3D tištěné modely s pružnými mechanismy |
| **Foto → 3D model** | Pipeline: fotka objektu → parametrický 3D model pomocí LLM (stretch goal) |

## Struktura repozitáře

```
preparation/     Checklisty, packing list, timeline
web/             Webová prezentace projektu
print-materials/ Podklady pro laminované A4 informační listy
subprojects/     Odkazy na dílčí repozitáře
assets/          Fotky, QR kódy, loga, modely
tools/           Pomocné nástroje (hledání fotek, budoucí automatizace)
```

## Tým

- **Filip Novotný** – fyzik, maker, tiskař, programátor
- **Rodina** – od 7 let po 40+ – každý přispívá po svém
