# Master checklist – MakerFaire KV 2026

## Před akcí (2+ týdny)

### Logistika
- [ ] Registrace na MakerFaire potvrzena
- [ ] Domluvený transport (auto, přívěs?)
- [ ] Zjištěn přesný rozměr stánku a počet stolů
- [ ] Zjištěna dostupnost elektřiny (kolik zásuvek, jaký příkon)
- [ ] Pojištění / odpovědnost zkontrolována

### Tiskárny
- [ ] Voron 2.4r2 – kompletní funkční test
- [ ] Voron 0.2 – kompletní funkční test
- [ ] Dostatek filamentu (min. 2 cívky PLA, 1 PETG)
- [ ] Náhradní trysky, bowden, pojistky
- [ ] Testovací tisk – demo model pro ukázku na místě

### RC auto
- [ ] Auto funkční (aktuálně rozbitý – opravit!)
- [ ] Firmware nahrán a otestován
- [ ] Baterie plně nabité
- [ ] Ovladač spárován a funkční
- [ ] Náhradní baterie

### Henna
- [ ] Henna pasta čerstvě připravená
- [ ] Šablony vytištěné / připravené
- [ ] Testovací aplikace na kůži

### Prezentační materiály
- [ ] Laminované A4 vytištěny (viz `print-materials/`)
- [ ] QR kódy vygenerovány a vytištěny
- [ ] Stojánky na A4 připraveny
- [ ] Web nasazen a funkční

### Photo-to-3D (stretch goal)
- [ ] Pipeline otestovaná end-to-end
- [ ] Demo připravené (fotka → model)

## Den před akcí

### Balení
- [ ] Vše zabaleno dle packing listu (`preparation/packing-list.md`)
- [ ] Tiskárny bezpečně zabalené (vibrace!)
- [ ] Křehké věci označené
- [ ] Prodlužovačky a kabely sbalené
- [ ] Notebook nabitý + nabíječka přibalena
- [ ] Auto naloženo, nic nechybí

### Finální kontrola
- [ ] Baterie nabité (RC auto, notebook)
- [ ] Filament nachystán v tiskárnách
- [ ] Demo modely vytištěny
- [ ] Henna pasta uložena v lednici

## Na místě (den akce)

### Příjezd a setup
- [ ] Příjezd v čas (dle organizátorů)
- [ ] Vyložení a kontrola – nic se nerozbilo?
- [ ] Stoly a prostor připraveny
- [ ] Elektřina zapojena a otestována
- [ ] Tiskárny zapnuty, zahřáty, testovací tisk
- [ ] RC auto otestováno na místě
- [ ] Laminované A4 vystaveny na stojáncích
- [ ] QR kódy viditelně umístěny

### Během akce
- [ ] Střídání u stánku (někdo vždy přítomný)
- [ ] Fotodokumentace průběhu
- [ ] Sbírání kontaktů / zpětné vazby

## Po akci

### Úklid
- [ ] Vše sbaleno
- [ ] Prostor uklizen
- [ ] Nic nezapomenuto na místě

### Follow-up
- [ ] Fotky zpracovány a nahrány
- [ ] Poděkování organizátorům
- [ ] Zpětná vazba sepsána (co příště lépe)
- [ ] Sociální sítě – příspěvek z akce
